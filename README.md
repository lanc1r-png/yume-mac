# Yume для Mac (Catalyst)

Сборка: GitHub → Actions → «Build Mac app» → Run workflow → артефакт `Yume-mac`.
Внутри `Yume-mac.zip` лежит `Yume.app`.

Первый запуск (приложение без платной подписи, только ad-hoc):
1. Распаковать zip, перетащить `Yume.app` в «Программы».
2. Правый клик → «Открыть» → «Открыть».
3. Если macOS всё равно блокирует: Настройки → Конфиденциальность и безопасность → внизу «Всё равно открыть».
4. Или в Терминале: `xattr -cr /Applications/Yume.app`

Иконка: положить `icon-1024.png` в корень репозитория.
